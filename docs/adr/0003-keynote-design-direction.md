# 3. Design direction: prototype A "Keynote"

Date: 2026-11-22. Status: accepted.

Of the three UI prototypes (PR #27 in the old repo), we carry over A "Keynote": Apple-inspired, huge type, one idea per screen, store-style configurator with sticky summary, three rings as the hero object. Built with Tailwind CSS and shadcn/ui; motion (Framer Motion) is a later pass.
